# 📋 Attendance Gap Detector
**SAIT AI Automation Engineer Evaluation — Scenario A**

---

## What It Does

Teachers currently spend **20–40 minutes per class per week** manually checking which students have attendance below the required threshold before exams. This tool eliminates that entirely.

You upload a CSV or Excel attendance sheet → the tool flags every student below your chosen threshold → exports a clean PDF or CSV report → and uses the **openai** to auto-draft a personalized warning letter for each flagged student.

---

## Features

| Feature | Details |
|---|---|
| 📁 File upload | CSV and Excel (.xlsx / .xls) |
| ⚙️ Configurable threshold | Default 75%, adjustable per run |
| 🚩 Auto-flagging | Highlights students below threshold with deficit days |
| 📊 Visual report | Color-coded table with progress bars |
| 🤖 AI warning messages | Claude generates a formal warning letter per flagged student |
| ⬇️ Export | Download as CSV or PDF (with AI messages embedded) |

## How to Run

### 1. Clone the repo
```bash
git clone https://github.com/YOUR_USERNAME/attendance-gap-detector.git
cd attendance-gap-detector
```

### 2. Create a virtual environment
```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Add your API key
```bash
cp .env.example .env
# Open .env and replace "your_api_key_here" with your Anthropic API key
```
Get a free API key at [console.anthropic.com](https://console.anthropic.com)

### 5. Run the app
```bash
python app.py
```

Open your browser at **http://localhost:5000**

## Input File Format

Your CSV/Excel file needs at minimum:

| Column | Accepted names |
|---|---|
| Student name | `Name`, `Student Name`, `Student` |
| Roll number | `Roll No`, `Roll`, `ID`, `Enrollment` |
| Days present | `Present`, `Days Present`, `Attended` |
| Total days | `Total`, `Total Days`, `Working Days` *(optional — can be set globally)* |

A sample file is included at `sample_data/sample_attendance.csv`.

## Bonus — AI Warning Messages
Each flagged student gets a personalized formal warning letter generated by **openai**. The prompt includes the student's name, roll number, attendance percentage, deficit days, and required threshold. Letters can be viewed, copied, or regenerated from the UI, and are embedded in the exported PDF.
